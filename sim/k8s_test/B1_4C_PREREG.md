## 3. 怎么证明「前缀缓存真的关了」（**不能只看命令行**）

读 `vllm:cache_config_info{…}` 里的 `enable_prefix_caching` 标签，**必须是 `False`**。

## 4. 预热协议（**顺序现在写死**）

- 预热 = **完整跑一遍 5 条提示词**，顺序固定为：
  **`p01_rep8` → `p02_rep12` → `p03_rep16` → `p04_rep20` → `p05_rep24`**，**串行**（一次一条）。
- **每条臂各预热 W = 3 遍**。预热结果落盘，文件名带 `warmup_` 前缀，
  **不参与主比较**（只用来回答 Q3）。
- 预热在**该臂的全部正式测量之前**完成，中间不插入别的动作。
- **臂的顺序固定：先 `baseline`，后 `disagg`**（与 B1 一致，不额外引入新变量）。

## 5. 正式测量协议

- 每条臂正式跑 **R = 3 遍**完整的 5 条，**串行**，独立编号：
  `baseline4c_r1/r2/r3` 与 `disagg4c_r1/r2/r3`。
- 请求参数固定：`temperature=0`、`seed=0`、`max_tokens=64`、
  `return_token_ids=true`、`logprobs=5`、`stream=false`。
- **配对规则（先定死）**：主比较是 **`baseline4c_r{k}` ↔ `disagg4c_r{k}`**（k = 1,2,3），
  即 3 组 × 5 条 = **15 对**。
- 辅助比较（只回答 Q3，不做主判定）：
  `baseline4c_r1↔r2`、`baseline4c_r2↔r3`、`disagg4c_r2↔r3`。

## 6. 判定规则（**先定死**）

- **等价**：15 对**全部**在 `token_ids` 口径上逐位相同 ⇒ 写「在本配置、本批输入下等价」。
- **不等价**：只要有**一对**不同 ⇒ 写「不等价」，并**逐条列出**首次分歧的位置与两侧 token。
- **禁止**把「意思差不多 / 同义改写」改判为通过。**B1 已经因为这条被否掉一次。**
- **禁止**事后调整这里的任何阈值。

## 7. 首次分歧的分类规则（**先定死，避免事后讲故事**）

在首次分歧的那一步，令：

- `a` = **对照臂（baseline）**在该步实际选的 token
- `b` = **拆分臂（disagg）**在该步实际选的 token

从两边该步的 `logprobs`（top-5）取概率（用 `exp(logprob)` 还原成概率）：

- 记 `pb(a)`、`pb(b)`、`pd(a)`、`pd(b)`
- 记两臂各自的 top1 与 top2 概率差 `gap_b`、`gap_d`

**分类规则**：

- 判为 **「近并列翻转」**，当且仅当 **两臂都满足 `gap < 0.10`**；
- 否则判为 **「确定性路径差异」**。

无论判成哪一类，**原始概率数字必须一并给出**，不能只给分类标签。
若某侧的 token 没进对方的 top-5，**如实写「未进 top-5」**，不补猜。

## 8. 失败与重跑纪律（沿用 B1 的 R1/R2/R4）

- **每次尝试都留档**：独立的 arm 标签 + `record.csv` 一行，含 UTC 起止与退出码。
- **失败不重跑顶替**：某次失败就记 FAIL 并**继续往下走**，不把那一条重发一次。

- 脚本层面由 `no_clobber` 强制：产物已存在就**拒绝写入**。
