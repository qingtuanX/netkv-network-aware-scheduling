## 4. 指标定义（**冻结**）

设某条请求上，两条臂的 `token_ids` 在**下标 i** 处首次不同。记：

- `a` = **对照臂（单机）** 在下标 i 选的词
- `b` = **拆分臂** 在下标 i 选的词
- `pa` / `pb` = 对照臂在该步给 `a` / `b` 的**概率**
- `qa` / `qb` = 拆分臂在该步给 `a` / `b` 的**概率**

### E1（主指标）「竞争词比值」

```
r_base   = pb / pa        对照臂把"对方选的那个词"打了自己的几折
r_disagg = qa / qb        拆分臂把"对方选的那个词"打了自己的几折
m        = min(r_base, r_disagg)        ← **主统计量**
```

`m` 越接近 1，说明**两臂各自对这两个词都越不在乎**。

**分档（冻结；只作描述，不作通过/不通过）**：

| 档 | 条件 | 含义 |
|---|---|---|
| A | `m ≥ 0.90` | 两臂**都近乎并列** |
| B | `0.50 ≤ m < 0.90` | 有明显倾向但仍接近 |
| C | `m < 0.50` | 两臂**各自都有明确偏好**，分歧不是并列造成的 |

**报告要求**：给出 `r_base`、`r_disagg`、`m` 的**完整分布**（最小/中位/最大）与各档计数，
**并附每一步的原始 top 概率**。**不设通过线。**

### E2（辅助指标）「翻过去需要多大余量」

- **噪声地板 `Δ`**：在**所有两边选同一个词**的步上，取两臂 top-5 并集内每个 token 的
  `|p_base − p_disagg|` 再取最大值，记为一个样本。报告它的**中位数与 p90** ——
  这是"两台机器本来就会有的数值差"的量级。
- **决策余量 `M`**：在**首次分歧那一步**，各臂"自己选的词"与"对方选的词"的概率差
  （对照臂 `|pa − pb|`、拆分臂 `|qa − qb|`）。
- **报告 `M / Δ`**：翻过去所需的余量，相当于普通数值差的几倍。

**预注册的读法（冻结）**：`M/Δ` 接近或小于 1 ⇒ 与"被数值噪声翻过去"**相容**；
`M/Δ ≫ 1` ⇒ 分歧**不能**用数值噪声解释，应记为真实差异。
**这条只用于解释，不产生新的通过标准。**
