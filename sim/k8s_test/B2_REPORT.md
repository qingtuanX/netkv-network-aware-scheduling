## 4. 解释边界（写论文照抄）

base 臂 1 张 GPU、拆分臂 2 张 GPU——以上数字是**"部署方式整体开销"**
（含算力配置不同、流水线并行、KV 传输、代理跳数），**不得**称为"传输成本"；
KV 字节数/次数/失败单独报。`chunk_gap_s` 只是文字块间隔；
`avg_token_gap_s` 只解释为"整段输出时间跨度除以 token 数"；
服务端 `vllm:request_time_per_output_token_seconds` 只作整体交叉核对（不逐请求配对）。
固定 64 词（ignore_eos）保证工作量可比，"自然停止"场景未覆盖。
