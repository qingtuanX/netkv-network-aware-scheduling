## 0. 术语先说明（第一次出现就解释）

| 文中写法 | 人话 |
|---|---|
| logprobs / 上报概率 | 服务把"每一步每个候选词的分（概率）"打印出来给你看 |
| argmax | 每步选分最高的那个词 |
| 贪婪解码（temperature=0） | 严格每步选分最高的词，不掷骰子 |
| teacher forcing | 把一段已知的前缀喂给模型，算它在下一步给每个词的分 |
| 本地裁判 | 在本机用自己的模型副本重算一遍分布，当"第三方秤" |
| 矛盾步 | 服务吐出的词**不是**它自己上报分布里分最高的那个（temperature=0 下不该发生） |
| 近并列 | 两个候选词的分差小到可以认为"模型不在乎选哪个" |
| 预注册 | 采数之前先把判据写死存档，防止看完结果再挑标准 |

## 1. 一个问题（只此一个）

> **Q：vLLM 0.31.0 上报的 logprobs，能不能当作"模型在该步的真实偏好"用于 4c 诊断？**

三个结局，各自的后续动作在 §6 写死：

| 结局 | 含义 | 后续 |
|---|---|---|
| **可用** | 上报概率与选择行为自洽 | `B1_4C_PREREG_2.md` 解卡，按原样执行 E1/E2 |
| **有条件可用** | 上报值本身不可信，但**本地裁判**能替代 | E1/E2 改用本地裁判的概率执行（§6 给具体改法） |
| **不可用** | 两者都不行 | 按路径④另立"不依赖概率"的诊断方案（新文件，不在本方案里顺手改） |

## 2. 判据（**冻结，采数后不得放宽**）

### U1：服务上报值是否自洽

对每一步：`argmax(该步上报分布) == 服务吐出的词`。

- **可用** ⟺ 全部步命中（矛盾步数 = 0）。temperature=0 下这是硬要求，没有容差。
- 已知线索（不作为本方案的证据，只作为背景）：A10 云端那批数据实测矛盾步 **81/373 = 21.7%**。
  本方案在本机**重新**测这个数，不引用旧数下结论。

### U2：本地裁判能否替代（两个层次都要算；只有 U1 判"不可用"时它才决定后续动作）

- **U2a（方法验证）**：对象是**本方案两个环境臂自己的**输出前缀（v2 题组 + 阳性对照题）。
- **U2b（用途验证，关键）**：对象是**云端 v1 数据里 B1 两条臂的前缀**
  （`b1_4c_20261008T002222Z` 的 `arm_*_r*.json`，**已有的数据，不花钱**）——
  本地裁判要当**云端**诊断的秤，必须先证明它能复现**云端臂**的行为；
  **U2a 全过但 U2b 不过，最终结论仍是"不能替代"**。
  U2b 的用途**只限测量仪校验**，不用来验证任何 4c 假设（遵守裁定 6）。

每个层次里，对每条臂的**每个前缀**，本地裁判（§3 探针 D）算出该步分布，记：

- `命中` = 本地 argmax == 该臂吐出的词；
- 对**未命中**的步，再看 `|p_local(本地argmax) − p_local(该臂吐的词)|`，记为 **gap_local**。

分级（冻结）：

| 判定 | 条件 | 含义 |
|---|---|---|
| **完全可用** | 全部步命中 | 本地分布就是该臂行为的忠实刻画 |
| **有条件可用** | 未命中步**全部**满足 `gap_local ≤ 0.05` | 偏差只发生在"本地也认为没差"的位置；E1/E2 可用，但结论只在 gap 大的步上下 |
| **不可用** | 存在 `gap_local > 0.05` 的未命中步 | 本地秤与臂行为有实质分歧，不能替代 |

`0.05` 这个阈值的来源（工程取值，进限制）：上一轮 E2 实测"两臂同词步的概率差"中位 0.0018、
p90 0.0229、最大 0.0527 —— 0.05 落在"普通数值差"的上沿之外，取得保守。

分级表对 **U2a、U2b 分别下判定，取两者中较差的那个作为最终结论**。

### U3：测量自检（先过它，再看 U1/U2）

同一条臂的重复运行（r2 vs r3）必须**逐 token 逐位相同**。不相同 ⇒ 测量本身不可信，
**先修测量、不解读任何判据**（沿用 `B1_4C_PREREG_2.md` §4 E3 的规则）。

## 3. 探针矩阵（四条途径 × 两个环境臂）

### 3.1 环境臂（两个都要，理由在下面）

| 臂 | 服务参数 | 为什么要 |
|---|---|---|
| **eager** | 与 B1 逐条相同：`--enforce-eager`、`--no-enable-prefix-caching`、`--max-model-len 8192`、`--gpu-memory-utilization 0.85`、bf16 | 判定对象就是 B1 那套环境的概率 |
| **默认**（CUDA graph） | 同上，但**去掉** `--enforce-eager` | B0 本地跑的是这一套；数值路径不同是候选差异源，顺手隔离 |

其余锁定项（两臂相同、并与 B1 一致）：模型 `Qwen/Qwen2.5-1.5B-Instruct`
revision `989aa7980e4cf806f80c7fef2b1adb7bc71aa306`、vLLM **0.31.0**（与云端同一个 wheel 版本）、
torch 2.13.0+cu130、`seed=0`、`max_tokens=64`、`return_token_ids=true`、`logprobs=20`、
前缀缓存**关闭**（以 `/metrics` 的 `enable_prefix_caching="False"` 原文为证，不看命令行）。

⚠️ 本机是 **RTX 4060 Laptop（8 GB，算力 8.9）**，云端是 **A10（24 GB，算力 8.6）**。
跨卡数值差异**不是**本方案要解释的对象，而是 U2 本来就要量化的东西（"本地秤能不能替代"）。

### 3.2 探针（每个环境臂都跑 A/B/C/D）

| 探针 | 做什么 | 回答什么 |
|---|---|---|
| **A** completions 接口 | `/v1/completions` + `logprobs=20`（**B1 同款调用**），逐位核对 argmax vs 吐词 | U1 在 B1 同款接口下成立与否 |
| **B** chat 接口 | `/v1/chat/completions` + `top_logprobs=20`，同样核对 argmax vs 吐词 | 换一条 API 取值路径，矛盾是否消失 |
| **C** prompt_logprobs | 请求带 `prompt_logprobs=20`，取 prompt 各位置的分布 | 它与生成侧 logprobs 是否同源；与探针 D 的 prompt 位置分布能否对上 |
| **D** 本地裁判 | 本地 HF 用**同 revision 权重** teacher-force 前缀（本方案两臂的输出 **+ 云端 v1 两臂的输出**），逐步取分布 | U2a / U2b 的原料；顺带与 A/B/C 对账 |

**探针 B 的方法警告（写死）**：chat 接口会套 chat 模板，前缀与 completions **不同**，
所以 B 只做**接口内**自洽检查（argmax vs 吐词），**不做跨接口的分布对比**。

**探针 D 的计算口径（冻结）**：权重 bf16、前向 bf16、logits 转 fp32 后 softmax；
喂入的 prompt 一律用 **token_ids**、不重新分词：本方案两臂取自己采数产物里的 token_ids，
云端臂取 `arm_*_r*.json` 里的；哪一份缺 prompt token_ids，就用对应冻结提示词文件重新
tokenize 并核对长度（云端 p01 应为 636 token），**对不上就停**。

## 4. 提示词与采数协议

- **主组（5 条）**：`B1_4C_PREREG_2.md` §2 冻结的 v2 题组（`q01_rep6 … q05_rep22`），
  **逐字符照抄**，采数前用 `gen-prompts --preset v2` 重生成并 sha256 核对。
- **阳性对照（2 条）**：v1 的 `p02_rep12`、`p05_rep24`（上一轮已知会出矛盾步的题）。
  **用途只限"测量仪校验"**，不用于任何 4c 假设的验证（遵守作者裁定 6）。
- 每条题 × 每条臂 **3 遍**，**串行**，先预热 1 遍（预热不进统计）。
- 顺序固定：探针 **A → C → B**（B 走 chat 模板、前缀与别的路径不同，放最后单独采），
  D 在采数结束后离线算。

## 5. 输出（每个数都要能从产物复算）

| 输出 | 定义 | 判什么 |
|---|---|---|
| `矛盾率` | 矛盾步数 / 总步数，按 探针×环境臂 分列 | U1 |
| `命中率` | 本地 argmax == 臂吐词 的步占比，**按 U2a / U2b 分列** | U2 |
| `gap_local 分布` | 未命中步的 gap_local：最小/中位/最大 + 逐条明细 | U2 分级 |
| `上报 vs 本地 对账` | top-20 交集上概率最大绝对差（口径同 E2 噪声地板） | 描述性，不产生判定 |
| `同臂重复性` | r2 vs r3 逐位比较 | U3 |
