# B1 查价失败记录（2026-10-07，append-only）

> 用途：把"**为什么没查到**"写成可复核的记录，避免以后有人以为是漏查。
> 本文只记录**查询行为与页面反应**，不记录任何价格推测。
> 抓取方式一律为 `curl -sL --compressed -A "Mozilla/5.0" <URL>`，本机 Windows + Git Bash，
> 未登录任何账号、未使用任何 Cookie/令牌。

---

## 1. 结论一句话

**国内主流云厂商的 GPU 实例单价，在未登录状态下没有任何一家能抓到明文数字。**
腾讯云自己在官方文档里把这件事写明白了（原文见 §2.1）。
因此 `B1_PRICING.csv` 里所有 `category=gpu_instance` 的行都是 `price_status=未查到`。

已核实到价格的只有三类**非 GPU 机时**的成本项：腾讯云云硬盘、腾讯云公网带宽、AutoDL 存储。

## 2. 逐家记录

### 2.1 腾讯云（已有账号，但本任务不登录）

| URL | 观察 |
|---|---|
| `https://buy.cloud.tencent.com/price/gpu` | 返回 208,806 字节 HTML，但正文中 **`元` 出现 0 次**；正文只有导航与栏目名。价格为前端 JS 加载。 |
| `https://buy.cloud.tencent.com/cgi/v2/pricecenter/getCalculatorJsConfig` | 返回 `{"code":9,"msg":"验证CSRF失败，请重新登录"}`。带 Cookie 罐重试后同样失败。 |
| `https://buy.cloud.tencent.com/cgi/capi?cmd=price.getPriceTabData` | 同上，`code:9` 验证 CSRF 失败。 |
| `https://cloud.tencent.com/document/product/560/8025`（GPU 云服务器 计费说明） | **官方原文**："为保证获取到的价格的准确性，请您登录腾讯云账户后查看。" —— 这是最权威的"必须登录"证据。 |

**结论**：必须先登录腾讯云账户，才能在购买页/价格计算器看到 GPU 实例的按量单价。

### 2.2 阿里云

| URL | 观察 |
|---|---|
| `https://www.aliyun.com/price/product` | 返回 31,916 字节低代码页面外壳，正文 `元` 出现 0 次；价格为前端加载。 |
| `https://help.aliyun.com/zh/ecs/product-overview/billing-overview` 等计费文档 | 服务端渲染成功（89 KB），但正文 **`元` 出现 0 次**：阿里云帮助中心不公布单价。 |
| `https://help.aliyun.com/zh/ecs/user-guide/gpu-accelerated-compute-optimized-and-vgpu-accelerated-instance-families-1` | **能抓到**（规格表含 GPU 型号、显存、网络带宽），**但不含价格**。已存档。 |
| `https://help.aliyun.com/zh/ecs/developer-reference/api-ecs-2014-05-26-describeprice` | 有 `Price`/`OriginalPrice` 等**字段说明**，无示例价格数值。 |

**结论**：阿里云机型规格公开可得，单价要登录控制台的购买页或价格计算器。

### 2.4 UCloud

| URL | 观察 |
|---|---|
| `https://www.ucloud.cn/price` | 返回 Next.js 的 `[...not_found]` 404 页（6,881 字节）。 |
| `https://www.ucloud.cn/site/active/gpu.html` | **能抓到**：裸金属 GPU 的具体配置（显存/CPU/内存/硬盘），以及折扣信息（新客 9.9 元/24 小时、高校 1.4 折起、多卡 1.1 折起、RTX40 系 3.1 折起）。**没有单价**，页面上写的是"点击立即咨询查看配置方案和最新报价"。已存档。 |

**结论**：UCloud 的活动价（9.9 元/24 小时）是真实存在的**促销价**，但只给一台、限一种机型，B1 需要两台，不能单独满足。

### 2.5 AutoDL

| URL | 观察 |
|---|---|
| `https://www.autodl.com/price` | 返回 3,177 字节 JS 外壳（页面自己提示"需要使用 JavaScript"）。 |
| `https://www.autodl.com/docs/price/` | **能抓到完整计费规则**（关机即停计费、数据盘单独计费等），但价格一栏写的是"请以网站显示的现价为准"。已存档。 |
| `https://www.autodl.com/docs/gpu/` | **能抓到 GPU 型号 × 显存 × 算力对照表**，无价格。已存档。 |
| `POST https://www.autodl.com/api/v1/order/price/preview` | 返回 `{"code":"AuthorizeFailed","msg":"登录超时，请重新登录"}`。 |

**结论**：AutoDL 的计费**规则**是本次查到的最友好的一家（"实例开机开始计费，关机结束计费"），但单价必须登录后才显示。

## 3. 我**没有**做的事（避免误解为已核）

1. 没有注册、登录任何云账号，没有使用任何人的凭据。
2. 没有开任何付费实例，没有下任何订单，没有产生任何费用。
3. 没有用第三方比价站/博客/知乎文章里的价格数字 —— 那些不是一手来源，无法复核。
4. 没有把"促销价"当成"列表价"写进预算表（UCloud 那行已单独标 `促销价（非列表价）`）。
5. 没有对任何页面做大规模爬取或绕过登录/验证码的尝试。
